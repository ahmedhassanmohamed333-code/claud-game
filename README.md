# 💎 لعبة الجواهر

لعبة تعليمية: المعلم يتحكم في سير المراحل ويعطي "الذراع" لكل طالب، والطالب يلعب من جهازه بالأسهم (أو أزرار الشاشة). حتى 5 لاعبين والترتيب يظهر مباشرة (الأكثر جواهر ثم الأسرع).

## التشغيل
```bash
npm install
npm start
```
- المعلم: `http://localhost:3000/?teacher` (كلمة السر الافتراضية `1234`، غيّرها: `TEACHER_PASS=xxx npm start`)
- الطلاب: `http://عنوان-جهاز-المعلم:3000` (نفس الشبكة)

## تعديل الأسئلة والمتاهات
عدّل ملف `stages.json`. في المتاهة: `#` جدار، `S` البداية، `G` جوهرة، `M` وحش حارس.
